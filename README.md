# Skills de Canva para Codex

Dez skills reutilizáveis para planejar, criar e revisar peças no Canva. Cada pasta contém instruções, critérios de qualidade e referências.

## Instalação no Windows

Copie as pastas de `skills/` para `%USERPROFILE%\.codex\skills\` (ou para `skills` dentro do seu `CODEX_HOME` personalizado). Reabra o Codex e invoque pelo nome, por exemplo: `Use $canva-criar-carrossel-continuo para planejar um carrossel.`

## Base de estudo

A pasta `estudo/` reúne o estudo visual, os materiais de apoio e o catálogo. As referências separam observações, interpretações e lacunas. As folhas visuais completas permanecem no arquivo original `frames.zip`, separado deste projeto. Não há transcrição nem novos frames. Operações dentro do Canva dependem dos recursos disponíveis na integração.
